# Security Policy

Do not publish credentials, device identifiers, customer data, precise location, application logs, firmware packages, or an unpatched vulnerability in a public issue or pull request.

Use GitHub private vulnerability reporting or Security Advisory for vulnerabilities affecting an approved snapshot. Include the public release tag, platform, device/OS version, reproducible steps, and sanitized logs.

The public source does not include STRVSN firmware distribution credentials, App Store credentials, signing keys, or TestFlight automation. Public source access does not authorize modification of devices you do not own or control.
